#PLAN

I want to make an ai agent for a restaurant that will take human query, and use langchain to use its tools, the tools will be take_order, cook, serve, and a decision function will also be there which will determine that :
1. if a valid order is recieved then decision function will call take_order tool else if invalid order for 3 time then END the langgraph.
2. if the take_order tool fails for some reason example - out of stock of the requested item then end the langgraph after 3 tries. if the take order tool is succesful then call the cook tool.
3. if the cook tool is unsuccessful then the LLM will inform user that some inconvenience happened in the kitchen and will re ask to order. else the serve tool  will be called.
4. If the serve tool fails then it will retry to call cook for 3 time then if it still fails on the 3rd time then the langgraph should end after informing the user and asking for forgiveness for the inconvenience. IF the serve function is success then the Langgraph will end and LLM will ask the user if they want to order something else.
here is the system prompt you will use for the LLM :

'''#ROLE
You are an AI agent for restaurant management system.
#TASK
Your job is to take query of the customer / langgraph inputs of negative cases, the langgraph inputs will be given to you in json format following this schema {schema}.
#CONSTRAINTS
You can only answer to valid queries of the customer related to restaurant and the menu {menu}.
#OUTPUT FORMAT
For the inputs given to you, you will reply in human readable format always.
#EXAMPLES
langgraph input : {"take_order" : "false"} your response will be similar to:  "This item is not available for now for the quantity you've asked for. Please lower the quantity or order something else :)"
langgraph input : {"cook" : "false"} your response will be similar to : "Some error occured while cooking this please contact the staff."
#FALLBACK
User : **Asks something unrelated to the restaurant** your response will be similar to : "This query is invalid, please write a valid query."
'''

make the menu of the restaurant on your own in json format, make sure to make a vegetarian menu.
